# SKILL GAME

A premium mobile-first web application for skill-based contests and puzzles.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript ES Modules
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Firebase Hosting

1. Install Firebase CLI
2. Configure Firebase project
3. Deploy to Firebase Hosting
